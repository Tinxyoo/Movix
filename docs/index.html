Why Movix

Run Modes

四种模式,自由度由你掌控

Tab 键一键切换,从全规划到全自动,每一步都透明可控。把介入权交还给你,让 Agent 在最合适的尺度上工作。

1

Plan

只读分析,产出多步任务规划,确认后再动手。

2

Agent

自主执行但每个动作征求确认,安全与效率兼得。

3

Auto

默认

只读操作直接执行,写操作仍需审批。

4

YOLO

全自动执行,适合可信任务与 CI 场景。

DeepSeek V4 Native

为什么 为 V4 设计

Movix 围绕 V4 架构从零设计。用其它模型也能跑,但以下能力仅在 V4 完整生效——这是与通用 Agent 的根本区别。

reasoning_effort

推理强度三档

Shift+Tab 一键切换 auto / high / max,UI 实时显示当前档位。

thinking_mode

Token 级思考解析

状态机解析 <think> 边界,Scavenger + ArgRepair 自愈非法输出。

Pro ↔ Flash

双模型切换

Ctrl+T 手动切换 Pro ↔ Flash,按任务复杂度选择,贵模型用在刀刃上。

1M 上下文

大仓库不爆

分层窗口 + Prefix Cache + 语义压缩,百万级上下文稳定工作。

384K 输出

超长单次输出

自动 min(config, 384K) 防 400,大文件生成一次性完成。

Stream

流式输出

Token 级实时渲染,思考过程可展开/收起,写操作串行保证安全。

Toolchain

内置工具 全副武装

12 个核心工具 + 2 个技能工具 + MCP 动态扩展,覆盖开发全流程。从读取到执行、从搜索到回滚,每一步都深思熟虑。

read_file / write_file / patch_file list_dir run_command · 沙箱保护 search_code / grep git_status / git_diff / git_log web_search / web_fetch list_skills / use_skill MCP 服务器 · 动态注册
/review

四维代码评审

基于真实 diff 做正确性 / 安全 / 性能 / 风格评审,严重度分级 Blocker → Info。

/pricing

实时成本侧栏

侧栏实时 token + ¥ 估算,`/pricing` 一键拉取官方最新价目。

VerifyLoop

编译级自动校验

轮次末自动跑 cargo check / tsc 等检查,错误回灌模型自愈(最多 3 轮)。

Snapshot

内容寻址快照

写文件前建立差异快照,工具失败时回滚文件改动(注意:Shell 等外部副作用无法撤销)。

Keyboard

全键盘操作,手不离键

点击任意快捷键体验键位反馈,终端外也能完整体验 Movix 的工作流。键位经过反复推敲,让高频操作零思考。
